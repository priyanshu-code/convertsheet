# Feature Specification: Markdown & HTML Table to Excel Converter

## 1. Overview & Goal
Provide a 100% client-side, privacy-preserving converter for developers, analysts, and AI users to turn Markdown and HTML tables (such as those generated by ChatGPT, Claude, DeepSeek, or GitHub READMEs) into structured, downloadable Microsoft Excel (`.xlsx`) spreadsheets, CSV, and JSON files.

## 2. User Experience & Split Input UI
The converter page at `/convert/markdown-to-excel` will provide a dual-input interface:
1. **Direct Paste Textarea (Left/Top)**:
   - A clean, monospace code textarea with a quick "Paste from Clipboard" button, "Load Example Table" button, and auto-detection on text change.
   - Ideal for quick `Cmd+V` / `Ctrl+V` copying directly out of ChatGPT / Claude conversations.
2. **File DropZone (Right/Bottom)**:
   - Accepts `.md`, `.markdown`, `.html`, `.htm`, and `.txt` files via drag-and-drop or file picker.
3. **Data Preview & Settings**:
   - Tabular preview table showing detected column names and first rows.
   - Sheet name customization (default: "Sheet1" or markdown file title).
   - Instant "Convert & Download (.xlsx)" button.

## 3. Technical Architecture & Parsing Engine
### Engine: `src/lib/engines/markdown-table-engine.ts`
- Implements `IConverterEngine` with `parsePreview` and `convert`.
- **Markdown Parsing Logic**:
  - Detects standard GitHub Flavored Markdown (GFM) pipe tables: `| Header 1 | Header 2 |`.
  - Strips separator rows containing dashes and alignment colons (`| :--- | ---: |`).
  - Trims cell whitespace and handles escaped pipes (`\|`).
  - Auto-casts numeric strings (e.g. `$1,250.00` or `42.5%`) to numeric values when appropriate so Excel functions (`SUM`, `AVERAGE`) work natively.
- **HTML Table Parsing Logic**:
  - Uses native browser `DOMParser` (`text/html`) with zero third-party bundle weight.
  - Extracts rows from `<tr>` and cells from `<th>` and `<td>`.
  - Cleans inner HTML formatting (e.g. `<b>`, `<code>`, `<br>`) to clean text.
- **Workbook Generation**:
  - Uses existing `xlsx` (SheetJS) to generate valid OpenXML `.xlsx` binary buffers.
  - Auto-computes column widths based on maximum string length so headers aren't truncated when opened in Excel.
